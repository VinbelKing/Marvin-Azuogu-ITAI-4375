# Assignment 2 — Healthcare Dataset Analysis

**Course:** ITAI 4375 — AI in Healthcare  
**Institution:** Houston City College  
**Instructor:** Dr. Doreen Rosenstrauch

## Overview

Analysis of a 5-patient healthcare dataset using descriptive statistics. Demonstrates calculation of arithmetic mean for key clinical variables.

## Dataset

| Patient | Age | Heart Rate (bpm) |
|---------|-----|-----------------|
| 1       | 45  | 72              |
| 2       | 52  | 80              |
| 3       | 38  | 68              |
| 4       | 61  | 85              |
| 5       | 33  | 79              |

## Key Calculations

- **Average Age:** 45.8 years  
- **Average Heart Rate:** 76.8 bpm  
- **Method:** Arithmetic mean — sum of all values divided by number of observations

## Concepts Covered

- Descriptive statistics in healthcare data
- Arithmetic mean formula: `x̄ = (Σx) / n`
- Interpretation of patient-level clinical metrics
- Foundational data literacy for AI/ML in healthcare
